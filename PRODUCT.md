# Retro Universe (propuesta de web)

Inferido del brief de Ismail (13-10-2026); las suposiciones van marcadas.

- **Negocio:** RETRO UNIVERSE S.L., Mijas Costa (Las Lagunas, Málaga). Monta y vende arcades, bartops, pinball virtual (VPX / Future Pinball), Pandora Box, consolas retro y lámparas backglass. Más de 20 años, 3 años de garantía, servicio técnico propio, envío desde España.
- **Superficie:** landing + tienda de una página (modo Persuade). Demo para venderles una web nueva; no es la web oficial.
- **Público:** aficionados al retro de 30-55 años (suposición) que compran una máquina para casa, bar o sala de juegos; deciden por fotos, precio y confianza (garantía, soporte).
- **Acción principal:** añadir a la cesta y pedir por WhatsApp (+34 672 83 58 94) con el pedido redactado.
- **Mundo visual (fijado por el brief):** arcade / synthwave pulido. #0a0612, rosa #ff2e93, cian #27f0ff, amarillo #ffd23f, violeta #7a3cff. Syne 800 + Space Grotesk + Press Start 2P (solo etiquetas, botones, números). CRT, rejilla, sol, pixel-art.
- **Anti-referencias:** su WooCommerce actual (duplicados, OFERTA en todo, sin CTA), estética SaaS genérica, verde WhatsApp estándar.
- **Imágenes:** renders de estudio generados a partir de sus fotos reales (mismo producto y arte). En la web final, sus fotos.
